# Змейка

Классическая «Змейка» в браузере. Откройте `snake.html` — и играйте.

Управление: **W / A / S / D** (или **Ц / Ф / Ы / В** в русской раскладке). После проигрыша или победы (когда змейка заполнила всё поле) — **Пробел** или **Enter**, чтобы сыграть снова.

## Структура

- `snake.html` — страница, отрисовка и ввод с клавиатуры
- `game.js` — логика игры без DOM (движение, повороты, еда, столкновения, скорость, рекорд)
- `game.test.js` — тесты логики

## Тесты

Нужен [Node.js](https://nodejs.org) 18 или новее (на macOS: `brew install node`). Зависимости не нужны.

```
npm test
```

Это то же самое, что `node --test`.

Что покрыто: движение, поворот (без разворота на 180° и с очередью нажатий), рост после еды, столкновение со стеной и с собой (голова может зайти в клетку, которую в этот ход освобождает хвост), победа при заполненном поле, еда не появляется на змейке, ускорение каждые 10 очков, сохранение рекорда.
